# StoryForge Kids

StoryForge Kids is a local kids-only story app for ages 4 to 8 with a hardened Node backend, a config-driven browser dashboard, credit tracking, and OpenAI-powered story generation.

## Highlights

- Local Node server with API and static asset serving
- Server-owned story configuration for modes, experiences, and dashboard lanes
- Real local dataset folders used as grounding context
- Stripe Checkout billing for paid credit packs
- Local billing and usage tracking with backward-safe state loading
- Browser dashboard for Live, Planned, and Experimental story lanes

## Web deployment

Render is the best fit for this project.

Why Render fits this app well:

- This is a single Node web service
- The app benefits from a persistent disk for local billing and usage state
- Health checks are simple with `GET /healthz`
- `render.yaml` makes setup repeatable

The project now includes a ready-to-use [render.yaml](render.yaml) Blueprint.

### Render setup

1. Push this project to a Git repository.
2. Create a new Blueprint service in Render from that repository.
3. Set the secret env vars in Render:
   - `OPENAI_API_KEY`
   - `APP_BASE_URL`
   - `STRIPE_SECRET_KEY` if using paid billing
   - `STRIPE_PRICE_ID_STARTER`
   - `STRIPE_PRICE_ID_SPARK`
   - `STRIPE_PRICE_ID_DREAM`
   - `STRIPE_PRICE_ID_CASTLE`
   - `STRIPE_PRICE_ID_GALAXY`
4. Deploy.
5. Verify:
   - `/healthz`
   - `/api/status`

### Hosted runtime notes

The server supports:

- `PORT` for hosted environments
- `STORYFORGE_PORT` for local development
- `STORYFORGE_DATA_ROOT` for writable persistent app data
- `STORYFORGE_DATASET_ROOT` for alternate dataset storage
- `GET /healthz` for uptime and platform health checks

## Dataset folders

Put real dataset files into these folders:

- `datasets\english-corpora`
- `datasets\storywars`
- `datasets\common-corpora`
- `datasets\tiny-stories`
- `datasets\deepmind`

Supported file types:

- `.txt`
- `.md`
- `.jsonl`
- `.json`
- `.csv`

The server reads snippets from those files and uses them as local grounding context for story generation.

Current local dataset status after setup:

- `english-corpora`: downloaded COCA sample text package from corpusdata.org
- `tiny-stories`: downloaded sample rows from Hugging Face
- `common-corpora`: downloaded sample rows from Hugging Face and filtered English written examples
- `deepmind`: downloaded and decrypted the Tell Me A Story validation split plus a sample text file
- `storywars`: official paper saved locally, with a source note placeholder because a direct public corpus download was not available in this environment

## OpenAI setup

Set these environment variables before starting the server:

- `OPENAI_API_KEY`
- `OPENAI_MODEL` optional, defaults to `gpt-5-mini`
- `STORYFORGE_PORT` optional, defaults to `8788`
- `APP_BASE_URL` optional, defaults to `http://localhost:8788`
- `STRIPE_SECRET_KEY` to enable paid credits
- `STRIPE_PRICE_ID_STARTER`
- `STRIPE_PRICE_ID_SPARK`
- `STRIPE_PRICE_ID_DREAM`
- `STRIPE_PRICE_ID_CASTLE`
- `STRIPE_PRICE_ID_GALAXY`
- `OPENAI_INPUT_COST_PER_MILLION` optional, defaults to `0.25`
- `OPENAI_OUTPUT_COST_PER_MILLION` optional, defaults to `2`

Example in PowerShell:

```powershell
$env:OPENAI_API_KEY="your_api_key_here"
$env:OPENAI_MODEL="gpt-5-mini"
```

## App behavior

- Multiple story modes, including separate "Choose Your Way" features
- Ages 4 to 8
- Optional Stripe billing with paid story credits
- Free tier with 1 claimable story credit
- Five paid tiers for credit packs
- Local billing state in `data\billing.json`
- Local usage and estimated cost tracking in `data\usage.json`
- Config-driven story builder controls loaded from the server
- Feature dashboard grouped into `Live`, `Planned`, and `Experimental`
- Story experiences include Adventure, Mystery, Bedtime, their separate Choose Your Way variants, a Dr. Seuss-inspired Choose Your Way, and a 3-book space opera Choose Your Way
- Word count range scales by age from 500 to 1200 words
- Stories are generated by the AI backend using your local dataset files as stylistic grounding
