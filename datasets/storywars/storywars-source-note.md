# StoryWars Source Note

StoryWars is referenced by the ACL 2023 paper "STORYWARS: A Dataset and Instruction Tuning Baselines for Collaborative Story Understanding and Generation."

Official paper:
- https://aclanthology.org/2023.acl-long.171/

Repository cited in the paper:
- https://github.com/ylndu/storywars

Current status:
- The original StoryWars website mentioned by the paper has been closed.
- The cited repository does not currently resolve as a public live download endpoint in this environment.
- `storywars-paper.pdf` is saved in this folder as the official source reference.

Temporary local grounding approach:
- Use this note plus the paper PDF as a placeholder until a recoverable public story archive or mirror is added.
- If a recovered corpus is found later, place `.txt`, `.md`, `.json`, `.jsonl`, or `.csv` files in this folder and the StoryForge backend will ingest them automatically.
